# Agent 补全约定

从编译报告定位缺失映射、未绑定属性和未译文案。已有视觉报告时，先打开 `design.png`、`actual.png` 和 `diff.png`，结合 `data-uic-node` 或报告中的节点 ID 定位差异。对照 [设计约束卡](design-brief.md) 与锁定版本的组件清单和主题 token。

- 组件和变体映射写入 `ui-compiler.map.json`，修改后运行 `pnpm uic check-map`。
- 设计图层名、实例和变量绑定通过已选定的 OpenPencil 画布修改。在编辑器确认没有未保存冲突后保存。没有对应语义 token 的值保留报告，等待确定其设计语义。
- 数据、状态和回调接线放在手写容器。检查中文和英文词典的待译项，由手写词典补充。
- 所有 `*.generated.*` 文件由 `uic compile` 管理。遇到哈希冲突时先保留编辑内容并人工核对。

每轮重跑编译和验证，记录覆盖率、未映射项及浅深模式差异。最多三轮，到达编译无错误和视觉阈值后停止。仍有差异时保留对应证据和未完成项，交给人工处理。
