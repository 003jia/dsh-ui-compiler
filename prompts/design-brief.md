# DSH MCP 中心设计约束卡

路线 A（`.op`）和路线 B（`.fig`）使用本卡的同一份任务、样例数据、视口与人工编辑步骤。输出一份可选中和修改图层的稿件，保存到 `design/pages/mcp-center.op` 或 `design/pages/mcp-center.fig`。MCP 中心的现有实现仅作页面结构和操作语义的参考。稿件全部使用合成数据。

## 页面结构

- 按设置内容区域构图。独立预览用「MCP 中心」标题，宿主已显示标题时由容器省略。保持一条阅读主线。
- 工具栏包含搜索框「搜索名称或服务标识…」、状态筛选和「刷新状态」。筛选项依次为「全部 4」「已开启 1」「已关闭 1」「加载中 1」「失败 1」，默认选中「全部」。
- 按下表顺序排列四个条目。左侧放名称和传输方式，右侧放可读的状态和即时生效的开关。失败条目显示错误文字和「重连」。条目名称和传输方式所在区域可以展开。一次展示一个条目的详情。
- 第一个条目默认展开。详情含传输方式、连接配置、已注册工具、工具命名空间和配置标识。连接配置预览显示「刷新预览」和简短 JSON，支持复制与折行，长内容在预览区内部滚动。工具可展开查看说明和输入 schema。
- 列表下保留一句提示「开关即时生效。展开条目可预览连接配置和已注册工具。」加载、空列表、搜索无结果、列表加载失败、条目连接失败各有可读的提示。列表加载失败可用已有的「刷新状态」重试。

| 名称 | 传输方式 | 条目状态 | 开关 | 补充 |
| --- | --- | --- | --- | --- |
| 文档索引 | 标准输入输出 | 已开启 | 开启，可操作 | 展开；连接配置见下文。 |
| 任务目录 | 流式 HTTP | 已关闭 | 关闭，可操作 | 折叠。 |
| 本地资料 | 标准输入输出 | 加载中 | 开启，禁用 | 折叠；示例为切换操作处理期间。 |
| 团队笔记 | 流式 HTTP | 连接失败 | 开启，可操作 | 折叠；「连接超时，请重试」，显示「重连」。 |

「文档索引」详情的固定样例为传输方式「标准输入输出」、工具命名空间 `m-doc-index`、配置标识 `doc-index`、工具名称 `list_documents`、说明「列出示例文档」和 schema `{"type":"object"}`。配置文案为「只读预览，凭据与敏感参数已隐藏。」配置块显示以下 JSON。

```json
{
  "transport": "stdio",
  "command": "example-mcp"
}
```

## 画布和样式

| 项目 | 两条路线共用的规则 |
| --- | --- |
| 取证画布 | `MCP 中心/default` 为 768 × 800 px 的浅色中文帧，左右各 24 px，内容宽度上限 720 px。使用相同帧尺寸和语言取证。深色使用相同布局和变量的主题值。 |
| 窄容器 | 用 400 px 宽、左右各 16 px 检查换行。搜索可独占一行，筛选和右侧操作可换行，详情元数据自然断行，页面无横向滚动。 |
| 排版 | 系统字体。正文及说明 13px/20px，标题 16px/24px。普通文字 400，强调和标题最多 500。 |
| 节奏 | 间距以 4 px 为步长，相关控件间距 8 px，条目上下内边距 16 px，分组间距 20–24 px。平铺条目以 0.5 px 中性分隔线隔开。 |
| 控件 | 采用 DSH 原语的形态，紧凑控件使用 `--dsw-radius-sm`，常规控件使用 `--dsw-radius-md`。开关、状态筛选、展开和按钮保留可辨认的焦点。 |
| 语义色 | 页面底色使用 `--dsw-alias-bg-base`，内容主次使用 `--dsw-alias-label-primary` 与 `--dsw-alias-label-secondary`，线条用 `--dsw-alias-border-l2`。加载、失败、开启可用 `--dsw-alias-state-warn-label`、`--dsw-alias-state-error-primary`、`--dsw-alias-state-success-primary`，并保留文字。 |

浅色和深色绑定同一语义变量。变量名在 `.op` 中用 `dsw.alias.bg.base` 这类路径，在 `.fig` 中用 `dsw/alias/bg/base`。间距和圆角优先绑定目标主题里已有的 token，未绑定的数值保留供编译报告识别。

## 稿件标注

- 首稿创建 `MCP 中心/default`、`MCP 中心/loading`、`MCP 中心/empty`、`MCP 中心/error` 四个顶层帧。后三个分别显示「正在加载 MCP 服务…」「还没有配置任何 MCP 服务」「MCP 服务列表加载失败，请重试」。搜索无结果文案为「没有匹配的 MCP 服务」，可在 `_搜索无结果` 辅助帧展示。
- 工具栏、列表、条目和详情使用可读取间距、内边距和对齐方式的 auto-layout。列表命名 `servers[]`，第一个子项为编译模板，其余为可见数据样例，按编译契约进入报告。展开与失败处理属于不同条目状态，稿件须保留这些视觉样例和对应可编辑图层。
- 使用独立组件定义和真实实例。最少演示 `DSH/Button` 与 `DSH/Switch`，按钮 `refresh` 编译为 `onRefresh` 所需的交互名。按钮变体至少有 `variant` 和 `size`，开关至少有布尔 `checked` 和 `disabled`。搜索、筛选、折叠、状态和代码预览可复用 `DSH/Input`、`DSH/SegmentedControl`、`DSH/DisclosureRow`、`DSH/StateDot`、`DSH/CodeBlock`。设计库和最终 prop 清单按阶段 2 以目标版本声明为准。
- 静态文字图层用字典键命名，例如 `title`、`searchPlaceholder`、`statusFailed`、`hint`。列表数据文字图层用 `{name}`、`{transportLabel}` 或 `{statusLabel}`。辅助说明以 `_` 开头。实际控件及文字保留图层，不转换成位图或轮廓。
- 如工具只支持基本图层、缺少实例变体、布局属性或变量绑定，记录具体缺口与对应节点。在评分时按保存后的数据评估。

## 阶段 1 对比步骤

| 检查 | 共用操作与证据 |
| --- | --- |
| T1 Agent 出稿 | 给两条路线相同约束卡，打开各自原生稿件。留存初稿截图，并选中搜索、开关、详情文字，核查它们能逐层编辑。 |
| T2 人工编辑 | 用画布把工具栏间距从 8 px 改成 12 px，把搜索提示改为「搜索 MCP 服务…」。撤销与重做后分别核查两个属性；保留重做后的版本。 |
| T3 Agent 局部修改 | 在画布选中「文档索引」详情，只将详情内部间距由 8 px 改成 12 px。保存编辑前后节点记录，核对选区外的节点 ID 和属性。 |
| T4 保存重开 | 保存并关闭，重新打开同一文件。用相同视口与主题对照截图，核对图层树、属性、实例和绑定。 |
| T5 外部保存冲突 | 使用同一个实验稿副本，画布留一项未保存编辑，外部把标题写成「MCP 中心（外部修改）」后再尝试从画布保存。记录提示、两侧修改和磁盘文件结果。 |
| T6 读取能力 | 用不超过 50 行的脚本从保存后的稿件读取节点 ID/名称、文本、实例引用及变体、auto-layout 和变量绑定。从源文件与导出结果核对同一批节点。 |
| T7 DSH 体验 | 记录操作发生在 DSH 右侧工作台还是独立画布，以及在 `ui-lab` 中的工具连接、实际操作与日志。 |

评分和 G1 的通过条件以[项目执行方案](../UI%20设计编译器执行方案.md#阶段-1两条路线对比3-天-g1)为准。参考来源为 `dsh-minimal-settings` 技能、`~/dsh-plugin/desktop-plugins/ui-mcp-center/src/client/` 的 MCP 中心页面和字典、`~/dsh-plugin/dsh-src/packages/client/ui-theme/src/styles/` 的本机主题源码。
